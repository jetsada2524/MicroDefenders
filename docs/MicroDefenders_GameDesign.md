# MicroDefenders — เอกสารออกแบบเกม (Game Design Document)

> เกม 3D ยิงเชื้อโรค 2 ผู้เล่นแข่งกัน สไตล์ Pixar — ใช้ pointer gun ยิงเชื้อโรคก่อนมันจะบุกเข้าอวัยวะในร่างกาย (มุมมองแบบ x-ray) ใครคะแนนมากกว่าใน 2 นาทีเป็นผู้ชนะ

- **เวอร์ชันเอกสาร:** 0.1 (Concept)
- **วันที่:** 24 ก.ค. 2026
- **Engine:** Godot 4.7 (เกม) + Blender (โมเดล/เรนเดอร์ 3D)
- **สไตล์ภาพ:** 3D Animation, Pixar-style (นุ่ม โค้งมน สดใส ตัวเชื้อโรคน่ารักไม่น่ากลัว)
- **กลุ่มเป้าหมาย:** เด็กอายุ 6–12 ปี (เล่นครั้งละ 2 คนแข่งกัน เหมาะกับงานนิทรรศการ/ห้องเรียน/อาร์เคด)
- **แนวเกม:** Light-gun / Rail shooter แบบแข่งขัน (ไม่มีระบบกระสุน/รีโหลด) + edutainment (ร่างกายและระบบภูมิคุ้มกัน)

---

## 1. วิสัยทัศน์ (Vision)

MicroDefenders เปลี่ยน "การเรียนเรื่องเชื้อโรคและร่างกาย" ให้เป็น **เกมยิงสุดมันแบบ 2 คนแข่งกัน** เด็กสองคนสวมบทเป็น "หน่วยพิทักษ์ร่างกาย (Body Defenders)" ถือ pointer gun ยิงเชื้อโรคที่กำลังบุกเข้าสู่ร่างกายมนุษย์ (มองทะลุเห็นอวัยวะภายในแบบ x-ray) ก่อนที่มันจะไปถึงหัวใจ ปอด สมอง หรือกระเพาะ ยิงแม่นกว่า เร็วกว่า ใช้ "ยาฆ่าเชื้อ" ถูกชนิด = คะแนนเยอะกว่า = ชนะ!

หัวใจของเกมคือ 3 คำ: **เล็ง (Aim) → ยิง (Blast) → ป้องกัน (Defend)** — สนุก เร้าใจ และได้ความรู้เรื่องร่างกาย เชื้อโรค และยาไปในตัว

---

## 2. Core Gameplay Loop (รอบละ 2 นาที)

1. **เริ่มรอบ** — ร่างกายแบบ x-ray ปรากฏกลางจอ นาฬิกานับถอยหลัง 2:00 เริ่มเดิน
2. **เชื้อโรคบุก** — เชื้อโรคโผล่จากขอบร่างกาย (ผิวหนัง ปาก จมูก) เดินทางไปยังอวัยวะเป้าหมาย
3. **เลือกยา** — ยิงขวดยาในคลัง (กลางล่าง) เพื่อเลือกยาสีที่ต้องการมาถือ
4. **ผู้เล่นยิง** — 2 คนเล็ง pointer gun ยิงเชื้อโรคด้วย **ยาที่ตรงสี** (ตรงสี = ตายครั้งเดียว ใครยิงโดนก่อนได้คะแนน · ผิดสี = ไม่เกิดผล ไม่ได้คะแนน/อาจติดลบ)
5. **ป้องกันอวัยวะ** — อย่าให้เชื้อถึงอวัยวะ (ถ้าถึง = เสียแต้ม/อวัยวะติดเชื้อชั่วคราว)
6. **หมดเวลา** — เทียบคะแนน 2 ฝั่ง ผู้เล่นที่คะแนนมากกว่าคือผู้ชนะ 🎉

## 3. ฟีเจอร์ที่ต้องมี (Required Features)

### 3.1 ผู้เล่นใช้ Pointer Gun
- ผู้เล่นแต่ละคนถือ **pointer gun** เล็งไปที่จอเพื่อยิง (แต่ละคนมี crosshair สีของตัวเอง เช่น ฟ้า vs ส้ม)
- รองรับ input ได้หลายแบบ (เลือกตอน implement): light-gun จริง, เมาส์ 2 ตัว, gamepad, หรือกล้อง/IR pointer — ระบบภายในมองเป็น "ตำแหน่งเล็ง (aim position) + ปุ่มยิง" เหมือนกัน

### 3.2 2 ผู้เล่นแข่งกัน — Interface แบ่งซ้าย/ขวา ยิงเป้าหมายเดียวกัน
- จอเดียว ร่างกายเดียว **เป้าหมาย (เชื้อโรค) ชุดเดียวกัน**
- **HUD แบ่ง 2 ฝั่ง:** ซ้าย = ผู้เล่น 1 (ชื่อ, คะแนน, ยาที่ถืออยู่), ขวา = ผู้เล่น 2 — ตรงกลางบนคือ **นาฬิกา 2 นาที**
- crosshair 2 อันเคลื่อนอิสระบนจอเดียวกัน สีต่างกันชัดเจน

### 3.3 เชื้อโรคเดินทางเข้าสู่ร่างกาย → อวัยวะ (มุมมอง x-ray)
- ฉากหลักคือ **ร่างกายมนุษย์แบบ x-ray** มองเห็นอวัยวะภายใน (หัวใจ ปอด กระเพาะ ลำไส้ สมอง) เรืองแสงนุ่มๆ สไตล์ Pixar (ไม่น่ากลัว)
- เชื้อโรคโผล่จาก **จุดทางเข้า** (ปาก จมูก บาดแผลที่ผิวหนัง) แล้วเดินทางตาม "เส้นทาง" ไปยังอวัยวะเป้าหมาย
- ผู้เล่นต้องยิงให้ทันก่อนเชื้อถึงอวัยวะ — ยิ่งเข้าใกล้อวัยวะ เชื้อยิ่งเดินเร็วขึ้น/มีเสียงเตือน

### 3.4 ยิงเชื้อตัวเดียวกันได้ — ใครยิงโดนก่อนได้คะแนน (ตายครั้งเดียว)
- ผู้เล่นทั้งสองยิงเชื้อ **ตัวเดียวกัน** ได้ ระบบตัดสิน "ใครยิงโดนก่อน" (first-hit) ให้คนนั้นได้แต้ม เชื้อตายด้วยการยิงครั้งเดียว
- สร้างการแข่งขันเร้าใจ — ต้องเล็งไว เก็บให้เร็ว ก่อนอีกฝ่าย

### 3.5 เวลาเล่นแต่ละรอบ = 2 นาที
- นาฬิกานับถอยหลังจาก 2:00 กลางจอด้านบน · 10 วินาทีสุดท้ายเร้าใจ (เพลงเร่ง ตัวเลขกะพริบ)
- หมดเวลา = สรุปคะแนน ประกาศผู้ชนะ

### 3.6 Item ยาฆ่าเชื้อเฉพาะชนิด — ต้องใช้ยาให้ตรงสีกับเชื้อ (สำคัญ)
- คลังยากลางจอล่างมีขวดยา 5 สี: **เขียว / ม่วง / ส้ม / ฟ้า / แดง** ผู้เล่นยิงขวดยาเพื่อ "เลือกยา" มาถือ (แสดงในวงกลมมุมล่างของแต่ละฝั่ง)
- ยาแต่ละสีจับคู่กับเชื้อสีเดียวกัน: เขียว→แบคทีเรีย, ม่วง→ไวรัส, ส้ม→เชื้อรา, ฟ้า→พยาธิ, แดง→บอสซูเปอร์บั๊ก
- **ยิงด้วยยาที่ตรงสี** → เชื้อตาย ได้คะแนน (+ โบนัส/สาดโดนหลายตัวสำหรับยาถูกชนิด)
- **ยิงด้วยยาผิดสี → ไม่เกิดอะไรขึ้น** เชื้อไม่ตาย และ **ไม่ได้คะแนน**
  - *ตัวเลือกปรับสมดุล:* หักคะแนน **−50 ต่อการยิงผิด 1 ครั้ง** เพื่อกันการกดยิงรัวมั่ว (เปิด/ปิดได้ตอน tuning)
- **ความรู้:** ยาแต่ละชนิดใช้ได้กับเชื้อเฉพาะแบบ — ใช้ยาผิดชนิดไม่ได้ผล (เช่น ยาปฏิชีวนะใช้กับไวรัสไม่ได้) ปูพื้นแนวคิด "เชื้อดื้อยา" และ "ใช้ยาให้ถูกโรค"
- เมื่อเลือกยาแต่ละชนิด **กล่องข้อมูลความรู้** มุมซ้ายล่างจะแสดงคำอธิบายสั้นๆ ของยานั้น

> **หมายเหตุ (ยกเลิกแล้ว):** ระบบ reload อัตโนมัติเมื่อเลื่อน pointer ออกนอกจอ **ถูกยกเลิก** — ผู้เล่นยิงได้ต่อเนื่องไม่จำกัดกระสุน ความท้าทายอยู่ที่การ **เลือกยาให้ตรงสีกับเชื้อ** แทน

## 4. ไอเดียเสริม เพื่อความตื่นเต้น + ความรู้ (Edutainment Layer)

ส่วนนี้คือข้อเสนอเพิ่มเติมของผม เพื่อให้เด็ก "อยากเล่นซ้ำ" และ "ได้ความรู้ติดตัว":

**ตัวนำทางน่ารัก (Mascot).** น้อง **"กัปตันเม็ดเลือดขาว (Captain WBC)"** เม็ดเลือดขาวตัวกลมยิ้มแฉ่ง คอยพากย์ ให้กำลังใจ และสอนเกร็ดความรู้ ("เชื้อไวรัสยาปฏิชีวนะเอาไม่อยู่นะ ต้องใช้พลังภูมิคุ้มกัน!")

**เชื้อโรคหลายชนิด = ความรู้.** แยกประเภทชัดเจน สอนความต่างจริง:
- **แบคทีเรีย (Bacteria)** — รูปแคปซูล/แท่ง มีหางแส้ (flagella) จัดการด้วย "ยาปฏิชีวนะ"
- **ไวรัส (Virus)** — ทรงกลมมีหนาม จัดการด้วย "พลังภูมิคุ้มกัน/วัคซีน" (ยาปฏิชีวนะใช้ไม่ได้! — ความรู้สำคัญ)
- **เชื้อรา (Fungus)** — ก้อนฟูมีสปอร์ จัดการด้วย "ยาต้านเชื้อรา"
- **พยาธิ/โปรโตซัว (Parasite)** — ตัวยาวๆ ว่ายไว

**บอสซูเปอร์บั๊ก (Superbug Boss).** เชื้อดื้อยาตัวใหญ่ที่โผล่มาเป็นช่วง ต้องใช้ **ยาถูกชนิด** เท่านั้นถึงกำจัดได้ (สอนแนวคิด "เชื้อดื้อยา" และทำไมต้องใช้ยาให้ครบ/ถูกวิธี) — ยิงร่วมกัน 2 คนได้แต้มใหญ่

**ระบบคอมโบ/สตรีค (Combo & Streak).** ยิงโดนติดต่อกันได้ตัวคูณคะแนน เร้าใจและกระตุ้นความแม่นยำ

**ไอเทมพิเศษเพิ่มเติม:**
- **โล่วัคซีน (Vaccine Shield)** — ป้องกันอวัยวะชั่วคราว (สอนหลักการวัคซีน "ป้องกันก่อนป่วย")
- **สบู่/ล้างมือ (Hand-wash Combo)** — เคลียร์เชื้อที่จุดทางเข้าเป็นชุด (สอนสุขอนามัย)
- **ไข้ (Fever Boost)** — เร่งการกำจัดชั่วคราว (สอนว่าไข้คือกลไกป้องกันของร่างกาย)

**ความรู้เรื่องอวัยวะ.** เมื่อเชื้อมุ่งไปอวัยวะไหน แสดงชื่อ+หน้าที่สั้นๆ ("ปอด: ช่วยเราหายใจ อย่าให้เชื้อเข้า!") เด็กจดจำตำแหน่งและหน้าที่อวัยวะโดยไม่รู้ตัว

**การ์ดความรู้จบรอบ (Fun Fact).** สรุปเกร็ด เช่น "ล้างมือ 20 วินาทีช่วยลดเชื้อโรคได้เยอะมาก!"

**เสียงและฟีล (Juice).** เสียงยิง "ปิ่ว!" เชื้อแตกเป็นประกาย เสียงนับคะแนนรัว ตอนบอสมาจอสั่นเล็กน้อย — ทุกการยิงรู้สึกดี

**โหมดเสริม (ถ้ามีเวลา):** Co-op (ช่วยกันป้องกันร่างกายเดียว), เลือกด่านตามอวัยวะ (ด่านปอด/ด่านลำไส้), ระดับความยาก

## 6. สถาปัตยกรรมทางเทคนิค (Godot 4.7)

### 6.1 โครงสร้างฉาก (Scenes)
- `Main.tscn` — จัดการสถานะเกม (เมนู → เล่น → สรุปผล)
- `Arena.tscn` — ฉากหลัก: ร่างกาย x-ray + จุดสปอว์น + เส้นทางเชื้อ + อวัยวะ
- `Germ.tscn` — เชื้อโรค 1 ตัว (ชนิด, HP=1, ความเร็ว, สี/ยาที่ใช้ได้, path follow)
- `Organ.tscn` — อวัยวะ (ชื่อ, สถานะติดเชื้อ)
- `ItemPickup.tscn` — ไอเทมยา (ชนิดยา, สี)
- `PlayerCrosshair.tscn` — crosshair + ยาที่ถืออยู่ ต่อผู้เล่น
- `HUD.tscn` — คะแนนซ้าย/ขวา + นาฬิกา + ไอเทม

### 6.2 Input & Pointer Gun (2 ผู้เล่น)
- แต่ละผู้เล่น = `aim_position` (Vector2 บนจอ) + `fire` action + `equipped_medicine`
- แยก device ต่อผู้เล่น (mouse/joy/lightgun) map เข้าเป็น aim + fire
- **ยิง:** ยิง = `camera.project_ray` จาก aim_position → raycast ชนเชื้อ/ขวดยา
- **ไม่มีระบบกระสุน/รีโหลด** (ยกเลิกแล้ว) — ยิงได้ต่อเนื่อง ความท้าทายอยู่ที่เลือกยาให้ตรงสี

### 6.3 First-Hit + ตรวจสีของยา (3.4 + 3.6)
- เชื้อมี `alive := true` และ `required_medicine` · ยิงโดนตรวจ atomically กันการนับซ้ำ
- **ยาตรงสี** → เชื้อตาย + ได้คะแนน · **ยาผิดสี** → ไม่เกิดอะไรขึ้น ไม่ได้คะแนน (ตัวเลือก: หักคะแนน)
```gdscript
const WRONG_MEDICINE_PENALTY := -50   # ตั้ง 0 เพื่อปิดการหักคะแนน

func on_hit(by_player) -> void:
    if not alive: return
    if by_player.equipped_medicine != required_medicine:
        # ยาผิดสี: เชื้อไม่ตาย ไม่ได้คะแนน (อาจติดลบ)
        by_player.add_score(WRONG_MEDICINE_PENALTY)
        play_no_effect_fx()          # เด้งออก + เสียง "ติ๊ด" บอกว่าใช้ไม่ได้ผล
        return
    alive = false
    by_player.add_score(points + bonus)   # ยาตรงสี = ได้คะแนน + โบนัส
    play_pop(); queue_free()
```

### 6.4 เชื้อโรค + เส้นทาง (3.3)
- ใช้ `Path3D` + `PathFollow3D` จากจุดทางเข้าไปยังอวัยวะ · ความเร็วเพิ่มเมื่อเข้าใกล้เป้า
- สปอว์นเนอร์สุ่มชนิด/เส้นทาง/จังหวะ ปรับความถี่ตามเวลาที่เหลือ (ท้ายเกมถี่ขึ้น)
- ถ้าเชื้อถึงอวัยวะ → อวัยวะ "ติดเชื้อ" ชั่วคราว + หักแต้ม/เตือน

### 6.5 ระบบยา/ไอเทม (3.6)
- `Medicine { type, color }` · เชื้อมี `required_medicine` · ยิงไอเทม = `equip(medicine)`
- ยิงเชื้อด้วยยาถูกชนิด = โบนัส/สาดโดนหลายตัว · ยาผิดชนิด = ยิงได้ปกติแต่ไม่โบนัส (ไวรัส: ยาปฏิชีวนะไม่ได้ผล)

### 6.6 นาฬิกา + ตัดสินผล (3.5)
- Timer 120 วิ · หมดเวลา → เทียบ `p1.score` vs `p2.score` → ประกาศผู้ชนะ (เสมอ = Sudden Death 15 วิ)

## 7. ทิศทางศิลป์ (Art Direction — Pixar Style)

- **เชื้อโรคน่ารักไม่น่ากลัว:** ตากลมโต ยิ้ม/ยักคิ้วกวนๆ สีสดใส เคลื่อนไหว bouncy — เด็กสนุกไม่หวาดกลัว
- **ร่างกาย x-ray แบบเป็นมิตร:** **ร่างกายเต็มตัวยืน** โครงร่างสีฟ้าโปร่งใสเรืองแสงนุ่ม เห็นอวัยวะภายในครบตามตำแหน่งจริง (สมอง หลอดลม หัวใจแดง ปอดฟ้า-เขียว ตับ กระเพาะ ลำไส้เล็ก/ใหญ่) สีพาสเทลสดใส พื้นหลังโทนเทคโนโลยีมีประกายอนุภาค + วงแสงเรืองด้านหลัง — ดูสมจริงพอให้เรียนรู้ตำแหน่งอวัยวะ แต่ไม่น่ากลัว
- **แสง:** อบอุ่น มี rim light ให้ตัวละครดูฟู มีชีวิต
- **UI:** ปุ่ม/ไอคอนกลมมนใหญ่ อ่านง่าย สีคู่ผู้เล่น (ฟ้า/ส้ม) ชัดเจน
- **พื้นหลัง:** โทนเข้มนุ่มให้ร่างกายและเชื้อเด่น + ประกายฝุ่นเล็กน้อย
- **สร้างงานต้นฉบับเอง ไม่ลอกผลงานผู้อื่น**

## 8. ขอบเขต MVP vs. ส่วนขยาย

**MVP (ต้องมีให้ครบ):** pointer gun 2 ผู้เล่น + HUD ซ้าย/ขวา + ร่างกาย x-ray + เชื้อเดินทางสู่อวัยวะ + ยิงตัวเดียวกัน first-hit (ตายครั้งเดียว) + รอบ 2 นาที + **ยาต้องตรงสีกับเชื้อ (ผิดสี = ไม่ได้คะแนน/ติดลบ)** + ตัดสินผู้ชนะจากคะแนน

**ส่วนขยาย (ถ้ามีเวลา):** กัปตันเม็ดเลือดขาว, เชื้อหลายชนิด+ความรู้, บอสซูเปอร์บั๊ก, คอมโบ, โล่วัคซีน/ล้างมือ/ไข้, ข้อมูลอวัยวะ, การ์ดความรู้จบรอบ, โหมด Co-op/เลือกด่าน

> บริบทการใช้งาน: เล่นครั้งละ 2 คนแข่งกัน เหมาะกับงานนิทรรศการ/อาร์เคด — แต่ละรอบสั้น เริ่มใหม่ได้ไว
